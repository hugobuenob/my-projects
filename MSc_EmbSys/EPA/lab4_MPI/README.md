# Message Passing Interface (MPI)
MPI is a very powerful Application Programming Interfaces (APIs), one of the most extended to work on the message passing programming model for distributed memory systems. Not only does it allow the communication and the data transmission between multiple processors, but it can also communicate between multiple compute nodes, which provides a wide variety of communication modes and functions that simplify the data transfer significantly. Besides, it is easier to control than Pthread.
