# Wireless Sensor Networks

The Internet of Things (IoT) is a very wide concept behind our vision of the future: smart homes, smart cities... smart stuff. Nevertheless, this idea may be too high-level and vague, so this subject focuses on the lowest layer of IoT, Wireless Sensor Networks (WSN).

Using the "Cookies", a special hardware characaterized by its ability to stick several PCBs one on top of another (self-developed by our lab, CEI-UPM), together with the Operating System ContikiOS, this subject focuses on the communication protocols used to connect the nodes to each other using an ad-hoc strategy, as well as the communication between a client and a server (including mosquitto, mqtt). Ultimately, a final project of forbidden room-entry detection is implemented and tested.
